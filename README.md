# 跨园托位协同服务

本服务用于托位、候补申请、限时要约与跨园调度。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：园区、班组、家庭、候补申请、要约、席位、整改限制、审计事件。

名额按园区、班组与服务日期核算；整改中的班组不得发出新要约；并发确认只能占用一个席位；过期要约释放后仍保留原因与操作者。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/nursery_capacity.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
